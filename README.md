# แฟ้มสะสมผลงาน ประภัสพงษ์ ศรีกำพล

เว็บไซต์ Portfolio แบบ Static ที่สร้างด้วย HTML, CSS และ JavaScript ไม่ใช้ Backend, ฐานข้อมูล หรือ API Key และพร้อมเผยแพร่ผ่าน GitHub Pages

เว็บไซต์เปิดภาษาไทยเป็นค่าเริ่มต้น มีปุ่มสลับภาษาไทย/อังกฤษและปุ่มเปลี่ยนธีมสว่าง/มืด ทั้งสองการตั้งค่าจะถูกจดจำในเบราว์เซอร์ หน้าเว็บมีเมนูที่ปรับตามขนาดจอ เส้นวงจรพื้นหลังแบบเคลื่อนไหว และรองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์

## เปิดเว็บไซต์บนเครื่อง

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเปิดโฟลเดอร์นี้ในโปรแกรมแก้ไขโค้ดแล้วใช้ส่วนขยาย Live Server เพื่อดูเว็บไซต์ระหว่างแก้ไข

## แก้ไขข้อมูลและเพิ่มเนื้อหา

ข้อมูลต้นฉบับอยู่ในไฟล์ `data/portfolio-data.js` เปิดไฟล์นี้แล้วแก้ข้อความระหว่างเครื่องหมายอัญประกาศ โดยคงเครื่องหมายจุลภาคและวงเล็บไว้ เนื้อหาที่ไม่มีข้อมูลจะไม่แสดงเป็นช่องว่างบนเว็บไซต์

- แก้ชื่อ ชื่อเล่น คำแนะนำตัว ประวัติส่วนตัว และเป้าหมายได้ในไฟล์นี้
- ใส่ปีการศึกษาใน `education.year` เมื่อมีข้อมูลจริงที่ต้องการแสดง หากปล่อยเป็นข้อความว่าง เว็บไซต์จะซ่อนรายการนี้
- รายการทักษะอยู่ใน `skills` แต่ละรายการมีชื่อและคำอธิบาย
- ผลงานอยู่ใน `projects` เว็บไซต์จะแสดงผลงานทุกชิ้นที่มีชื่อ โดยใช้ชื่อ รายละเอียด และรูปที่ระบุในข้อมูลเดิม
- เพิ่มผลงานโดยคัดลอกตัวอย่างนี้ไปต่อท้ายรายการใน `projects` แล้วแก้ชื่อ คำอธิบาย และเส้นทางรูปภาพ

```js
{ title: "ชื่อผลงาน", description: "รายละเอียดผลงาน", image: "assets/images/projects/ชื่อรูป.jpg" }
```

- เกียรติบัตรอยู่ใน `certificates` แตะหรือคลิกภาพบนเว็บไซต์เพื่อขยายในตำแหน่งเดิม
- กิจกรรมเพิ่มเติมอยู่ใน `activities`; หากไม่มีรายการ เว็บไซต์จะซ่อนส่วนกิจกรรม

อย่าใส่ข้อมูลส่วนตัวหรือผลงานที่ไม่ต้องการเผยแพร่ต่อสาธารณะ ไฟล์ที่นำขึ้น GitHub Pages จะเปิดให้ดูตามการตั้งค่าคลังข้อมูล

## เพิ่มรูปภาพ

วางไฟล์รูปภาพไว้ในโฟลเดอร์ที่ตรงกับประเภท แล้วระบุเส้นทางใน `portfolio-data.js`

- รูปประจำตัว: `assets/images/profile/`
- รูปผลงาน: `assets/images/projects/`
- รูปเกียรติบัตร: `assets/images/certificates/`
- รูปกิจกรรม: `assets/images/activities/`
- เอกสาร PDF (ถ้ามี): `assets/documents/`

ใช้ JPG, PNG หรือ WebP และตั้งชื่อไฟล์โดยไม่ใช้ตัวอักษรพิเศษเกินจำเป็น

## เผยแพร่ด้วย GitHub Pages

1. สร้าง Repository ใน GitHub เช่น `portfolio` แล้วเลือก `Public` หากต้องการใช้ GitHub Pages ฟรี
2. อัปโหลด **เนื้อหาทั้งหมดในโฟลเดอร์นี้** ไปยัง Repository โดยให้ `index.html` อยู่ที่ระดับบนสุด
3. เปิด Repository แล้วเลือก **Settings**
4. เลือก **Pages** จากเมนูด้านซ้าย
5. ในหัวข้อ **Build and deployment** เลือก **Deploy from a branch**
6. เลือก Branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
7. รอให้ GitHub Pages เผยแพร่ แล้วเปิด URL ที่แสดงในหน้า Pages (มักอยู่ในรูป `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`)
8. เมื่อแก้ข้อมูลหรือรูปในภายหลัง ให้อัปโหลดไฟล์ที่แก้กลับเข้า Repository ระบบจะเผยแพร่เวอร์ชันใหม่ให้อัตโนมัติ

หากตั้งชื่อ Repository เป็น `ชื่อผู้ใช้.github.io` URL จะเป็น `https://ชื่อผู้ใช้.github.io/` โดยตรง
